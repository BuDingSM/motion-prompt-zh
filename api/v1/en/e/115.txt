// Black and white / モノクロ
// Pack: photo (Photo looks, lighting & styles) · element 19 · Category: Tones & finishing looks
// What happens: The colourful beach photo loses its colour and becomes a black-and-white image in which only differences in brightness show the shapes.
// Motion spec:
//   - Brightness: 0.2126 R + 0.7152 G + 0.0722 B (Rec. 709)
//   - Contrast: ×1.18 around mid grey
//   - Cross-fades from the source photo (blue sky, sea, beach, red-and-white parasol, a person in orange) to the processed one; a slider at bottom right shows the amount
//   - Timing: the effect comes in from 0.6 s to 1.7 s, holds until 3.9 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// When to use it: For a timeless feel, or when shape, light and expression matter more than colour.
// Tags: black and white, monochrome, b&w, grayscale, desaturated, classic
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// Live demo: https://showheyohtaki.github.io/motion-prompt/#115
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 19
// 19 モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = gradeCell('bw', p => { const y = luma(p) / 255, v = clamp(0.5 + (y - 0.5) * 1.18) * 255; return [v, v, v]; });
