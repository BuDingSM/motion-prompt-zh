// Teal and orange / ティール＆オレンジ
// Pack: photo (Photo looks, lighting & styles) · element 21 · Category: Tones & finishing looks
// What happens: In the beach photo the darks, sky and sea move toward teal while skin, clothes and sand move toward orange, giving a film-like grade.
// Motion spec:
//   - Two tones: teal rgb(16,106,118) and orange rgb(255,156,80)
//   - Choice: brightness × 0.55 plus warmth (R − B, full at 90) × 0.6 picks the point between the two
//   - Brightness is kept (with contrast ×1.15), blended 78% over the original
//   - Cross-fades from the source photo (blue sky, sea, beach, red-and-white parasol, a person in orange) to the processed one; a slider at bottom right shows the amount
//   - Timing: the effect comes in from 0.6 s to 1.7 s, holds until 3.9 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// When to use it: For a blockbuster, trailer-like look with strong colour contrast.
// Tags: teal and orange, orange and teal, cinematic, color grading, blockbuster, film look
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// Live demo: https://showheyohtaki.github.io/motion-prompt/#117
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 21
// 21 ティール＆オレンジ: 暗い所と空・海を青緑（ティール）へ、肌や明るい所を橙へ寄せ、コントラストを少し上げる
CELLS[20] = gradeCell('teal', p => {
  const y = luma(p) / 255, s = sm(clamp((y - 0.12) / 0.7));
  const warm = clamp((p[0] - p[2]) / 90);                 // 赤みの強い色（肌・服・砂）ほど橙へ
  const tone = mix([16, 106, 118], [255, 156, 80], clamp(s * 0.55 + warm * 0.6));
  const f = clamp(0.5 + (y - 0.5) * 1.15) * 255 / Math.max(12, luma(tone));
  return mix(p, tone.map(v => Math.min(255, v * f)), 0.78);
});
