// 周辺減光（ビネット） / Vignette
// パック: photo (写真の表現・光と画風) · element 16 · カテゴリ: レンズ・カメラの効果
// 何が起きるか: 海辺の写真の四隅に向かって、なだらかに暗くなっていく。中央はそのままなので、画面の真ん中に目が集まる。
// 動きの仕様:
//   - 形: 縦を0.62倍につぶした楕円の放射グラデーション（中心＝画面の中心）
//   - 濃さ: 半径の45%までは0、80%で黒45%、四隅（100%）で黒85%
//   - 元の写真: 青空・海・砂浜・パラソル・人物（19〜23と同じ）
//   - 時間: 0.6〜1.7秒で効果が入り、3.9秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 主役に視線を集めたいとき、古いレンズの雰囲気を出したいとき。
// タグ: vignette, vignetting, dark corners, edge darkening, lens falloff, focus
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#112
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 16
// 16 ビネット（周辺減光）: 画面の四隅に向かってなだらかに暗くなり、中央に目が集まる
CELLS[15] = cell((k, w, h, u) => {
  const a = env(u);
  k.drawImage(beach(), 0, 0);
  k.save(); k.translate(CW / 2, CH / 2); k.scale(1, 0.62);
  const R = Math.hypot(CW / 2, CH / 2 / 0.62), g = k.createRadialGradient(0, 0, 0, 0, 0, R);
  g.addColorStop(0, 'rgba(0,0,0,0)'); g.addColorStop(0.45, 'rgba(0,0,0,0)'); g.addColorStop(0.8, rgb([0, 0, 0], 0.45 * a)); g.addColorStop(1, rgb([0, 0, 0], 0.85 * a));
  k.fillStyle = g; k.fillRect(-R, -R, R * 2, R * 2); k.restore();
  slider(k, a);
});
