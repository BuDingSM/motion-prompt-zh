// ハイキー / High-key
// パック: photo (写真の表現・光と画風) · element 17 · カテゴリ: 仕上げ・画風
// 何が起きるか: 灰色の背景で普通に写した静物が、白い背景・明るい光・ごく薄い影の写真に変わる。右下のヒストグラムが明るい側（右）に寄る。
// 動きの仕様:
//   - 背景: rgb(176,172,166) → rgb(252,251,249)（上）、机 rgb(128,120,110) → rgb(236,233,228)
//   - 光: 強さ 1 → 1.12、影の側の明るさ 42% → 86%
//   - 落ち影: 黒の濃さ 38% → 10%（6pxぼかし）
//   - ヒストグラム: 山の位置 0.3・0.55・0.78 → 0.78・0.9・0.96（0 = 黒、1 = 白）
//   - 時間: 0.6〜1.7秒で効果が入り、3.9秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 清潔感・軽やかさ・やさしさを出したい商品や人物の写真で。
// タグ: high-key, high key, bright, white background, airy, low contrast
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#113
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 17
// 17 ハイキー: 白い背景・明るい光・ごく薄い影。明るい色だけで画面を作り、ヒストグラムが右に寄る
CELLS[16] = cell((k, w, h, u) => stillLife(k, lerpKey(KEYS.mid, KEYS.high, env(u))));
