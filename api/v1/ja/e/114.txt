// ローキー / Low-key
// パック: photo (写真の表現・光と画風) · element 18 · カテゴリ: 仕上げ・画風
// 何が起きるか: 灰色の背景で普通に写した静物が、黒い背景に1灯だけを当てた写真に変わる。光の当たる側だけが浮かび、画面の大半が暗い。右下のヒストグラムが暗い側（左）に寄る。
// 動きの仕様:
//   - 背景: rgb(176,172,166) → rgb(12,12,13)（上）、机 → rgb(22,20,18)
//   - 光: 左上から。影の側の明るさ 42% → 5%、落ち影 38% → 85%
//   - スポット: (270,100) 中心の放射グラデーションで外側を暗く（半径の半分で黒55%、半径240pxで92%）
//   - ヒストグラム: 山の位置 0.3・0.55・0.78 → 0.03・0.1・0.55
//   - 時間: 0.6〜1.7秒で効果が入り、3.9秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 高級感・緊張感・ミステリアスな雰囲気を出したいとき。
// タグ: low-key, low key, dark, black background, moody, dramatic, chiaroscuro
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#114
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 18
// 18 ローキー: 黒い背景・横からの1灯。光の当たる縁だけが浮かび、画面の大半が暗い。ヒストグラムが左に寄る
CELLS[17] = cell((k, w, h, u) => stillLife(k, lerpKey(KEYS.mid, KEYS.low, env(u))));
