// モノクロ / Black and white
// パック: photo (写真の表現・光と画風) · element 19 · カテゴリ: 仕上げ・画風
// 何が起きるか: 色のある海辺の写真から色が抜け、明るさの差だけで形が見える白黒の写真になる。
// 動きの仕様:
//   - 明るさ: 0.2126R + 0.7152G + 0.0722B（Rec.709）
//   - コントラスト: 中間の灰色を中心に1.18倍
//   - 元の写真（青空・海・砂浜・赤白のパラソル・オレンジの服の人）から加工後へクロスフェード。右下のスライダーが効き具合
//   - 時間: 0.6〜1.7秒で効果が入り、3.9秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 時代を感じさせたいとき、色より形・光・表情を見せたいとき。
// タグ: black and white, monochrome, b&w, grayscale, desaturated, classic
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#115
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 19
// 19 モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = gradeCell('bw', p => { const y = luma(p) / 255, v = clamp(0.5 + (y - 0.5) * 1.18) * 255; return [v, v, v]; });
