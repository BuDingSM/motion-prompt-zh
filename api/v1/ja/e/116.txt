// デュオトーン / Duotone
// パック: photo (写真の表現・光と画風) · element 20 · カテゴリ: 仕上げ・画風
// 何が起きるか: 海辺の写真の色が、暗い所は濃い藍、明るい所はピンクの2色だけに置きかわる。
// 動きの仕様:
//   - 2色: 暗い所 rgb(32,26,118)（濃い藍）、明るい所 rgb(255,142,170)（ピンク）
//   - 明るさ（Rec.709）を中間の灰色中心に1.15倍してから、2色の間に割り当てる
//   - 元の写真（青空・海・砂浜・赤白のパラソル・オレンジの服の人）から加工後へクロスフェード。右下のスライダーが効き具合
//   - 時間: 0.6〜1.7秒で効果が入り、3.9秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: ポスター・音楽・SNSの画像を、ブランドの色で統一したいとき。
// タグ: duotone, two-tone, gradient map, color overlay, poster, graphic
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#116
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 20
// 20 デュオトーン: 明るさを2色（暗い所 = 濃い藍、明るい所 = ピンク）だけに置きかえる
CELLS[19] = gradeCell('duo', p => { const y = clamp(0.5 + (luma(p) / 255 - 0.5) * 1.15); return mix([32, 26, 118], [255, 142, 170], y); });
