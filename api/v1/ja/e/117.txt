// ティール＆オレンジ / Teal and orange
// パック: photo (写真の表現・光と画風) · element 21 · カテゴリ: 仕上げ・画風
// 何が起きるか: 海辺の写真の、暗い所・空・海が青緑（ティール）へ、肌・服・砂が橙へ寄り、映画のような色になる。
// 動きの仕様:
//   - 2色: ティール rgb(16,106,118)、オレンジ rgb(255,156,80)
//   - 寄せ方: 明るさ × 0.55 と赤み（R−B、90で最大）× 0.6 の和で2色の間を選ぶ
//   - 明るさはコントラスト1.15倍で保ち、元の色と78%で混ぜる
//   - 元の写真（青空・海・砂浜・赤白のパラソル・オレンジの服の人）から加工後へクロスフェード。右下のスライダーが効き具合
//   - 時間: 0.6〜1.7秒で効果が入り、3.9秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 映画のポスターや予告編のような、色の対比が強い画にしたいとき。
// タグ: teal and orange, orange and teal, cinematic, color grading, blockbuster, film look
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 動く見本: https://showheyohtaki.github.io/motion-prompt/#117
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 21
// 21 ティール＆オレンジ: 暗い所と空・海を青緑（ティール）へ、肌や明るい所を橙へ寄せ、コントラストを少し上げる
CELLS[20] = gradeCell('teal', p => {
  const y = luma(p) / 255, s = sm(clamp((y - 0.12) / 0.7));
  const warm = clamp((p[0] - p[2]) / 90);                 // 赤みの強い色（肌・服・砂）ほど橙へ
  const tone = mix([16, 106, 118], [255, 156, 80], clamp(s * 0.55 + warm * 0.6));
  const f = clamp(0.5 + (y - 0.5) * 1.15) * 255 / Math.max(12, luma(tone));
  return mix(p, tone.map(v => Math.min(255, v * f)), 0.78);
});
