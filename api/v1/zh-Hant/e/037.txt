// 慢動作 / Slow motion
// 類別包: camera (攝影機運動與轉場) · element 13 · 分類: 拍攝手法與時間效果
// 效果說明: In front of a fixed camera a person rises and falls slowly through a jump while leaves drift down slowly; the whole action is stretched out.
// 動效規格:
//   - Camera: completely fixed (height 1.3 m); only the subject moves
//   - Subject: a person 7 m away takes 3.8 s for one jump (0.5 s to 4.3 s); height = 4q(1-q)×1.1 m, a parabola peaking at 1.1 m, with q linear in time
//   - Both arms are raised while airborne; the person stands still for 0.5 s before the jump and 0.4 s after landing
//   - Leaves: 9 leaves fall from 3.4 m to the ground over 4.7 s while rotating, each offset by 1/9 of the cycle
//   - Top-right readout shows "120fps ×0.25" (playback stretched 4×)
//   - No hold and no cross-fade; loops seamlessly every 4.7 s
// 適用情境: To let viewers study a brief action or expression, or to emphasise an emotional peak.
// 標籤: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// 尺寸: 539x208 px · 週期: 9.4 s
// 依賴: kit camera -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 動態範例: https://budingsm.github.io/motion-prompt-zh/#037
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫方已清空畫布並完成 save/restore），w、h = 尺寸，u = [0, cycle) 內的秒數。畫面只由 u 決定。
// 以下是元素程式碼。CELLS、常數和輔助函式位於 kit 中。

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
