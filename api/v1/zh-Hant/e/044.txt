// 交叉溶解 / Cross dissolve
// 類別包: camera (攝影機運動與轉場) · element 20 · 分類: 轉場
// 效果說明: The next picture is laid over the current one and its opacity rises until it takes over; both show through each other midway.
// 動效規格:
//   - Join: 1.5 s, from 1.5 s to 3.0 s; the incoming picture's opacity goes 0 → 100%
//   - Easing: quadratic ease-in-out (about cubic-bezier(0.45,0,0.55,1)); 50% at 2.25 s
//   - The outgoing picture stays fully opaque underneath and the incoming one is drawn on top (the outgoing one is not faded out first)
//   - Camera: fixed in both pictures (A at height 1.4 m; B at height 1.6 m, pitch +0.1 rad); the subjects do not move either
//   - Only the outgoing picture shows for 0–1.5 s, only the incoming one for 3.0–4.7 s
//   - Alternates A→B and B→A every 4.7 s (9.4 s for the round trip); top-right readout shows "A → B" / "B → A"
// 適用情境: To convey a gentle passage of time or change of place, or to move into a memory.
// 標籤: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition
// 尺寸: 539x208 px · 週期: 9.4 s
// 依賴: kit camera -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 動態範例: https://budingsm.github.io/motion-prompt-zh/#044
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫方已清空畫布並完成 save/restore），w、h = 尺寸，u = [0, cycle) 內的秒數。畫面只由 u 決定。
// 以下是元素程式碼。CELLS、常數和輔助函式位於 kit 中。

// @element 20
// 20 クロスディゾルブ
CELLS[19] = shot(abCell((k, w, h, u, A, B) => blend(k, kk => A(kk, w, h), kk => B(kk, w, h), eIOs(P(u, 1.5, 3.0)))));
