// 黑白 / Black and white
// 類別包: photo (攝影風格、光線與鏡頭效果) · element 19 · 分類: 調色與風格
// 效果說明: The colour drains from the same landscape; the sun and the light on the figure turn grey and the shapes read only by their brightness.
// 動效規格:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Conversion: each colour becomes the grey of its luminance (0.2126R + 0.7152G + 0.0722B), contrast ×1.25 around 140
//   - For example the figure #4D5A75 → about #4D4D4D, the sun #F5A524 → about #B5B5B5
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// 適用情境: For a timeless feel, or when shape, light and expression matter more than colour.
// 標籤: black and white, monochrome, b&w, grayscale, desaturated, classic
// 尺寸: 539x208 px · 週期: 5 s
// 依賴: kit photo -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 動態範例: https://budingsm.github.io/motion-prompt-zh/#115
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫方已清空畫布並完成 save/restore），w、h = 尺寸，u = [0, cycle) 內的秒數。畫面只由 u 決定。
// 以下是元素程式碼。CELLS、常數和輔助函式位於 kit 中。

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
