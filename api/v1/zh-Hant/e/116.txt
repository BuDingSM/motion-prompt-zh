// 雙色調 / Duotone
// 類別包: photo (攝影風格、光線與鏡頭效果) · element 20 · 分類: 調色與風格
// 效果說明: The colours of the same landscape are replaced by a range between just two colours: indigo in the darks and pink in the lights.
// 動效規格:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Two colours: #1F2A5C for the dark end, #FF9FB2 for the light end
//   - Conversion: from each colour’s luminance L, t = ((L − 70) / 180)^2.4, and the two colours are mixed by t (this spreads the light tones apart)
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// 適用情境: To unify posters, music artwork or social images in brand colours.
// 標籤: duotone, two-tone, gradient map, color overlay, poster, graphic
// 尺寸: 539x208 px · 週期: 5 s
// 依賴: kit photo -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 動態範例: https://budingsm.github.io/motion-prompt-zh/#116
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（呼叫方已清空畫布並完成 save/restore），w、h = 尺寸，u = [0, cycle) 內的秒數。畫面只由 u 決定。
// 以下是元素程式碼。CELLS、常數和輔助函式位於 kit 中。

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
