請使用「運動路徑（Motion path）」，它是「動態圖形動效（第二輯）」中的一個名稱。
Motion Prompt #126

它是什麼：Moves along a curve that you define
範例展示：A paper plane follows a dotted path, turning as it goes and looping the loop on the way.
規格：
- One pass per 4.7 s, from off-screen left to off-screen right. The path is x = 270 + 112θ − 150·sinθ, y = 106 − 74·cosθ for θ = −π→π, which makes a loop at the top centre.
- θ advances in proportion to time (so the speed along the path is not constant; the loop looks slower).
- The plane turns to the path direction: angle = atan2(74·sinθ, 112 − 150·cosθ).
- The path is shown in advance as a dotted line (width 6, dash 2/15). A mint trail of 24 segments (0.03 in θ each) follows, thinner and fainter towards the back.
適用情境：Use it whenever something should follow a set route: a flying object, a car, a journey on a map.
