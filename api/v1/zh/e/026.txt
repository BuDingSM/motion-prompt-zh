// 直摇 / Tilt
// 类别包: camera (摄影机运动与转场) · element 02 · 分类: 镜头运动
// 效果说明: The camera stays in place and pivots upward, from a person at ground level up to the top of a tower.
// 动效规格:
//   - Camera: position fixed (height 1.4 m); pitch only, -0.06 rad → +0.36 rad (-3° → +21°, about 24° in total)
//   - Timing: 0.5 s to 3.4 s (2.9 s), cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1))
//   - Subject: a person stands still 7 m ahead; a 9.5 m tower (antenna tip at 11.8 m) stands 26 m away behind
//   - On screen everything slides downward: the person leaves at the bottom while the tower top and its antenna enter
//   - Return: hold 3.4–4.2 s, then cross-fade back to the start over the last 0.5 s (one pass = 4.7 s)
//   - Top-right readout shows the angle in whole degrees (-3° → +21°)
// 适用场景: To show the height or scale of a building or a person.
// 标签: tilt, tilt up, pitch, vertical, look up, camera move
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动态示例: https://budingsm.github.io/motion-prompt-zh/#026
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（调用方已清空画布并完成 save/restore），w、h = 尺寸，u = [0, cycle) 内的秒数。画面只由 u 决定。
// 以下是元素代码。CELLS、常量和辅助函数位于 kit 中。

// 02 ティルト
CELLS[1] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ pitch: lerp(-0.06, 0.36, p), y: 1.4 }), { person: { z: 7 }, tower: [0, 26], buildings: false, sun: [7, 13, 40], sunScale: 0.4 }),
  p => `${Math.round(lerp(-0.06, 0.36, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
