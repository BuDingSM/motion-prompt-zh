// 擦除转场 / Wipe
// 类别包: camera (摄影机运动与转场) · element 21 · 分类: 转场
// 效果说明: A vertical edge moves from left to right and the next picture replaces the current one behind it.
// 动效规格:
//   - Join: 1.1 s, from 1.7 s to 2.8 s; the edge travels from just outside the left side (x = -4 px) to just outside the right side (x = 543 px)
//   - Easing: cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1))
//   - The incoming picture shows left of the edge and the outgoing one right of it; neither picture moves (a reveal by clipping, not a push)
//   - Edge: a 4 px blue vertical line, visible only while it is moving
//   - Camera: fixed in both pictures; the subjects do not move either
//   - Alternates A→B and B→A every 4.7 s (9.4 s for the round trip); top-right readout shows "A → B" / "B → A"
// 适用场景: To mark a clear change of scene or topic, or to switch between the two sides of a comparison.
// 标签: wipe, linear wipe, reveal, clip, edge, left to right, transition
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动态示例: https://budingsm.github.io/motion-prompt-zh/#045
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（调用方已清空画布并完成 save/restore），w、h = 尺寸，u = [0, cycle) 内的秒数。画面只由 u 决定。
// 以下是元素代码。CELLS、常量和辅助函数位于 kit 中。

// @element 21
// 21 ワイプ
CELLS[20] = shot(abCell((k, w, h, u, A, B) => {
  const p = eIO(P(u, 1.7, 2.8)), ex = p * (w + 8) - 4;
  A(k, w, h);
  if (p > 0) { k.save(); k.beginPath(); k.rect(0, 0, ex, h); k.clip(); k.fillStyle = '#fff'; k.fillRect(0, 0, w, h); B(k, w, h); k.restore(); }
  if (p > 0 && p < 1) { k.fillStyle = C.blue; k.fillRect(ex - 2, 0, 4, h); }
}));
