// 轮廓光 / Rim light
// 类别包: photo (摄影风格、光线与镜头效果) · element 02 · 分类: 打光方式与时段
// 效果说明: The surroundings go dark and two lights behind the person, left and right, draw thin bright edges only along both sides of the head and shoulders; the plan at the bottom right shows where the two lights are.
// 动效规格:
//   - Scene 1: a head-and-shoulders figure in front of a horizon at y 150 (head centre x 270, y 78, radius 29 px, no face or hair). 
//   - Background: light scene → dark scene (sky #2B2D33, ground #24252A); figure #4D5A75 → #1F2128
//   - Bright edges: two copies of the figure in amber #FFC75A, shifted 3.5 px left and right and 2.5 px up, placed behind the dark figure (3.5 px wide edges)
//   - Plan at the bottom right (66×66 px): lights at ±135° seen from above (behind, left and right); top-right readout "±135°"
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// 适用场景: To separate a person or product from a dark background and show its shape.
// 标签: rim light, rim lighting, edge light, backlight, kicker, outline, studio
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 动态示例: https://budingsm.github.io/motion-prompt-zh/#098
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（调用方已清空画布并完成 save/restore），w、h = 尺寸，u = [0, cycle) 内的秒数。画面只由 u 决定。
// 以下是元素代码。CELLS、常量和辅助函数位于 kit 中。

// @element 02
// リムライト: 周りが暗くなり、斜め後ろ左右の2灯で頭と肩の輪郭だけが細く光る
CELLS[1] = cell((k, u) => {
  const a = env(u);
  stagePortrait(k, pal(BASE, DARK, a));
  k.save(); k.globalAlpha = a; k.fillStyle = BASE.lit;
  for (const dx of [-3.5, 3.5]) { k.save(); k.translate(dx, -2.5); bustPath(k, PX, PY, PR); k.fill(); k.restore(); }
  k.restore();
  bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
  plan(k, [[Math.PI * 0.75, a], [-Math.PI * 0.75, a]]);
  hud(k, '±135°');
});
