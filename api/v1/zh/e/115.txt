// 黑白 / Black and white
// 类别包: photo (摄影风格、光线与镜头效果) · element 19 · 分类: 调色与风格
// 效果说明: The colour drains from the same landscape; the sun and the light on the figure turn grey and the shapes read only by their brightness.
// 动效规格:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Conversion: each colour becomes the grey of its luminance (0.2126R + 0.7152G + 0.0722B), contrast ×1.25 around 140
//   - For example the figure #4D5A75 → about #4D4D4D, the sun #F5A524 → about #B5B5B5
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// 适用场景: For a timeless feel, or when shape, light and expression matter more than colour.
// 标签: black and white, monochrome, b&w, grayscale, desaturated, classic
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 动态示例: https://budingsm.github.io/motion-prompt-zh/#115
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（调用方已清空画布并完成 save/restore），w、h = 尺寸，u = [0, cycle) 内的秒数。画面只由 u 决定。
// 以下是元素代码。CELLS、常量和辅助函数位于 kit 中。

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
