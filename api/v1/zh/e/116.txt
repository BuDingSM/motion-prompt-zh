// 双色调 / Duotone
// 类别包: photo (摄影风格、光线与镜头效果) · element 20 · 分类: 调色与风格
// 效果说明: The colours of the same landscape are replaced by a range between just two colours: indigo in the darks and pink in the lights.
// 动效规格:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Two colours: #1F2A5C for the dark end, #FF9FB2 for the light end
//   - Conversion: from each colour’s luminance L, t = ((L − 70) / 180)^2.4, and the two colours are mixed by t (this spreads the light tones apart)
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// 适用场景: To unify posters, music artwork or social images in brand colours.
// 标签: duotone, two-tone, gradient map, color overlay, poster, graphic
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://budingsm.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 动态示例: https://budingsm.github.io/motion-prompt-zh/#116
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（调用方已清空画布并完成 save/restore），w、h = 尺寸，u = [0, cycle) 内的秒数。画面只由 u 决定。
// 以下是元素代码。CELLS、常量和辅助函数位于 kit 中。

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
