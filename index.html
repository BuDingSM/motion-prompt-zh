AIに頼むための「名前」のライブラリ

名前が分かれば、AIに頼めます。

モーショングラフィックス、カメラワーク、UIパーツ、LP・Webサイトの演出、写真の表現の名前を、動く見本つきで並べました。名前を見つけたら、そのままAIに伝えてください。プロンプトをコピーすれば、動きの仕様と参考実装も一緒に渡せます。

スキルで導入

ターミナルで実行します。入れたあとは「motion-prompt スキルで #012 と #045 を使って」と番号で頼めます。

npx skills add showheyohtaki/motion-prompt

プロンプトで導入

下の文を Claude Code や Codex に貼ると、AIがスキルを入れて使い方を教えてくれます。

https://github.com/showheyohtaki/motion-prompt を読んで、motion-prompt スキルをこの環境に入れてください。入れたら、使い方を3行で教えてください。

使い方

  1. 1

    名前を見つける

    見本を眺めて、頭の中にある動きを探します。名前は、そのままAIへの指示に使えます。#012 のような番号でも呼べます。

  2. 2

    プロンプトをコピー

    詳細にある「プロンプトをコピー」を押します。動きの仕様と、参考実装のURLが入った文がコピーされます。

  3. 3

    AIに貼る

    Claude Code や Codex に貼ります。「今のこの部分を、これに差し替えて」と一言添えると伝わりやすくなります。

スキルを入れると、番号だけで頼めます

motion-prompt スキルを入れておくと、AIが番号から仕様とコードを自分で取りに行きます。プロンプトを毎回コピーする必要はありません。

  • motion-prompt スキルで #012 と #045 を使って、30秒の紹介動画を作って
  • 今のタイトルの出し方を #005 に差し替えて

参考実装について

見本はすべて Canvas 2D で書いた、時刻だけで絵が決まる関数です。外部ライブラリは使っていません。1コマずつ描けるので、動画の書き出しにも使えます。
