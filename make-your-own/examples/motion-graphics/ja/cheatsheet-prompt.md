# 早見表の画像を作ったときの依頼文（モーショングラフィックス回）

同じフォルダの `cheatsheet.png` を作ったときに、画像生成AIへ渡した文です。[プロンプト3](../../../prompts/ja/03-cheatsheet-image.md) の記入例の2つ目として置いています。カメラワーク回（青の線画アイコン）と違い、こちらは左端を「動画のカードを小さく再現したカラーのサムネ」にしています。

添付した画像は2枚です（このリポジトリには入れていません）。

- `ref_sheet.png`: 先に作った早見表。文字とレイアウトの見本
- `ref_cards.png`: 動画の各カードの見せ場を並べた画像。`render.mjs --sheet` で作れるコマ一覧から切り出せます

## 1回目

```
日本語の早見表（チートシート）画像を作り直してください。添付は2枚です。
- ref_sheet.png: 今の早見表。**文字・レイアウト・余白・文字の色と大きさはこのまま一字一句変えない**
- ref_cards.png: 動画の各カード（01〜24）の見せ場のコマ。左の青い数字がカード番号

変えるのは**左端のアイコン列だけ**です。今は青一色の線画ですが、これを「その番号の動画カードを小さく再現したカラーのサムネ」に差し替えます。

## 出力
- サイズ: 1024x1152（横:縦＝8:9）。最初から8:9の構図で全体を収める
- 3案を作る。案ごとにサムネの描き方（単純化の度合い）を少し変える。文字とレイアウトは3案とも同じ
- 画像生成で作る（コードで描く、ref_cards.png を切り貼りする、などはしない）

## サムネの共通ルール
- 形と大きさと位置は今のアイコン枠と同じ（横長の小さな角丸の四角・24行で左端がそろう）。枠線は付けず、**地は濃紺（#0F1A3D）のベタ**
- 色は動画と同じ4色＋白だけ: 青 #3B7BFF／コーラル #FF6B5C／黄 #FFC83D／ミント #2EDBA8。フラットな塗り。グラデーション・写真・絵文字・細かい模様は使わない
- とても小さいので、ref_cards.png のコマを**大きく単純化**して、主役の形を太く大きく描く。サムネの中に細かい文字は入れない（下で指定した1〜3文字だけ）
- サムネ以外（番号の青、区分見出しの青、黒の日本語名、グレーの英語名と説明、区分の角丸の枠、白い背景、最下段のグレーの帯）は ref_sheet.png のまま

## 2回目（選んだ1枚を添付して、サムネを2つだけ直す）

画像生成AIは、1回で24個すべてを思った通りには描きません。選んだ1枚を添付し、直す所だけを言葉で指定します。

```
添付の画像を**そのまま**再現し、左端のサムネ2つだけ直した画像を作ってください（画像の編集）。文字・レイアウト・ほかの22個のサムネ・色・余白は一切変えない。サイズは 1024x1152（8:9）。2案作る。

直す2つ:
- 05（マスクリビール）のサムネ: 今は白い「A」が全部見えて赤い線の上に乗っている。これを「線の下から文字がせり上がってくる途中」に直す。濃紺の地の**中央より少し下**にコーラルの横線を1本。白い太字「A」は**上の半分（とがった頭と斜めの2本の途中まで）だけ**が線の上に見え、横棒より下の部分と2本の足は線でスパッと水平に切れて見えない。線より下は濃紺の地だけで何も描かない。線は文字の下端に接するだけで、文字の上には重ねない
